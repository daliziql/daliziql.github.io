## 维护

这是无需构建、无需 JavaScript 的静态页面，由 GitHub Pages 发布 `main` 分支根目录。

增减站点时，编辑 `index.html` 中的目录条目，同时更新站点数量、页脚日期及本文件中的清单。仅收录允许公开展示的站点。

本地预览：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```
